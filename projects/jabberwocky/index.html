Enterprise Payment Gateway Integration

Overview

Led the integration of multiple payment vendors including American Express and Visa networks into Delta Air Lines’ enterprise payment gateway system.

Key Achievements

  • Amex Connectivity: Implemented secure connection protocols for American Express payment processing
  • Visanet Integration: Established robust Visa network integration for global payment processing
  • Scalability: Designed system to handle enterprise-scale transaction volumes
  • Security: Implemented industry-standard security protocols for payment data protection

Technical Implementation

Architecture

  • Microservices-based payment processing
  • RESTful API design for vendor integrations
  • OAuth token management for secure authentication

Infrastructure

  • AWS cloud deployment
  • Kubernetes orchestration
  • Load balancing for high availability

Impact

Improved payment processing efficiency and enabled seamless integration with multiple payment vendors, enhancing customer experience across Delta’s global operations.

Tech used

  • Java Spring Boot
  • REST APIs
  • OAuth
  • AWS
  • Kubernetes
