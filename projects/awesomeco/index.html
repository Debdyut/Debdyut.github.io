AWS Payment Engine Migration

Overview

Led the modernization and migration of Delta Air Lines’ legacy payment engine to AWS cloud infrastructure, improving scalability, reliability, and performance.

Technical Implementation

Infrastructure Setup

  • Bare-metal Kubernetes setup on AWS EC2 following security guidelines
  • Kubernetes cluster administration and application deployment
  • Kong API Gateway integration with AWS ELB

Security & Compliance

  • RBAC authorization service development with Spring Boot
  • Implementation of enterprise security standards
  • Compliance with airline industry regulations

Migration Strategy

  • Phased migration approach to minimize downtime
  • Performance optimization during transition
  • Comprehensive testing and validation

Key Results

  • Scalability: Enhanced system capacity to handle peak travel periods
  • Reliability: Improved system uptime and fault tolerance
  • Performance: Reduced payment processing latency
  • Cost Optimization: Leveraged AWS services for cost-effective operations

Technologies

Modern cloud-native architecture using AWS services, containerization, and microservices patterns.

Tech used

  • AWS EC2
  • Kubernetes
  • Kong API Gateway
  • Spring Boot
  • Docker
